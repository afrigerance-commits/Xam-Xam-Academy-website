## Comprendre le chapitre
Une primitive F de f sur un intervalle vérifie F′=f. Deux primitives diffèrent d’une constante. Pour f continue sur [a,b], l’intégrale de a à b est F(b)−F(a). Si f est positive, cette intégrale représente une aire sous la courbe ; si f change de signe, elle est une aire algébrique. Une primitive de xⁿ pour n entier positif ou nul est xⁿ⁺¹/(n+1).

## Méthode de résolution
Chercher une primitive, la vérifier en dérivant puis calculer F(b)−F(a). Pour une aire géométrique, traiter séparément les changements de signe.

:::attention
L’intégrale d’une fonction négative est négative avec des bornes dans l’ordre croissant ; une aire géométrique est positive.
:::

## Exercice 1 — Application
Calculer l’intégrale de 2x de 0 à 3.

:::correction
Une primitive est x². Résultat : 3²−0²=9.
:::

## Exercice 2 — Raisonnement
Trouver toutes les primitives de 3x²−2.

:::correction
F(x)=x³−2x+C, où C est une constante réelle. Sa dérivée est bien 3x²−2.
:::

## Exercice 3 — Transfert et justification
Calculer l’intégrale de 0 à 2 de 3x² dx.

:::correction
Une primitive est F(x)=x³. L’intégrale vaut F(2)−F(0)=8. Une constante ajoutée à la primitive se simplifie dans la différence. L’aire géométrique coïncide ici avec l’intégrale puisque la fonction est positive sur l’intervalle.
:::
