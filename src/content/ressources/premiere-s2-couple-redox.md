## Les notions essentielles
Une oxydation est une perte d’électrons ; une réduction est un gain. Un oxydant capte des électrons, un réducteur les cède. Le couple Ox/Red relie deux formes d’une espèce selon Ox + ne⁻ ⇌ Red. Une réaction d’oxydoréduction combine deux demi-équations dont les électrons se compensent. Les électrons n’apparaissent pas dans le bilan global d’une réaction entre deux réactifs.

## Méthode
Écrire les demi-équations, égaliser le nombre d’électrons échangés puis additionner et simplifier.

:::attention
Un oxydant se réduit lorsqu’il réagit ; un réducteur s’oxyde.
:::

## Exercice 1 — Application
Écrire la demi-équation du couple Cu²⁺/Cu.

:::correction
Cu²⁺ + 2 e⁻ ⇌ Cu. Cu²⁺ est la forme oxydante, Cu la forme réductrice.
:::

## Exercice 2 — Aller plus loin
Associer Zn → Zn²⁺ + 2 e⁻ et Cu²⁺ + 2 e⁻ → Cu. Bilan ?

:::correction
Zn + Cu²⁺ → Zn²⁺ + Cu. Les électrons sont échangés puis disparaissent du bilan.
:::
