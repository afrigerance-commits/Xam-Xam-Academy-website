## Les notions essentielles
Une oxydoréduction peut se produire sans solution aqueuse. Le transfert électronique se décrit alors notamment avec les nombres d’oxydation. La réduction d’un oxyde métallique par un réducteur peut former le métal. Une oxydation augmente le nombre d’oxydation et une réduction le diminue. Certaines réactions sont fortement exothermiques : elles ne constituent pas des expériences domestiques.

## Méthode
Attribuer les nombres d’oxydation selon les règles, repérer leurs variations puis équilibrer le bilan.

:::attention
Les réactions thermiques de réduction peuvent être dangereuses ; l’exercice porte sur l’équation et le bilan, pas sur une réalisation à domicile.
:::

## Exercice 1 — Application
Dans Fe₂O₃, quel est le nombre d’oxydation du fer si O vaut −II ?

:::correction
2x+3(−2)=0, donc x=+III.
:::

## Exercice 2 — Aller plus loin
Pour Fe₂O₃ + 2 Al → 2 Fe + Al₂O₃, identifier oxydation et réduction.

:::correction
Fe passe de +III à 0 : il est réduit. Al passe de 0 à +III : il est oxydé. L’équation conserve Fe, Al et O.
:::
